# Quick Start

This guide walks you from first launch to your first export.

## 1. Install and launch
- Install the app with the Windows installer.
- Start the app from the Start menu.
- Choose New Project or open an existing project folder.

## 2. Create a project
- Use File -> New Project.
- Choose a dedicated folder (local disk recommended).
- Optional: copy demo data if offered.

## 3. Import data
- Chronograph: open the Chronograph Import module and load your files.
- CSV: use the CSV import flow if you maintain component data externally.
- GRT: use the GRT import flow for Gordon Reloading Tool files.

## 4. Analyze
- Open Historical Analysis to review sessions.
- Select sessions to compare or view trends.
- Check audit fields to confirm provenance.

## 5. Export
- Export selection to CSV or JSON in Historical Analysis.
- Use Reports -> Export Pack to create a shareable zip.

## 6. Backups
- The project folder contains your data.
- Copy the project folder or use Export Pack for a portable backup.

## Safety
Reloading and ballistics work is inherently risky. Read the safety notes in
safety_disclaimer.md and follow published load data.
