# User Guide

## Overview
Hjemmelading is an offline-first desktop app for load development,
component tracking, chronograph analysis, and ballistics planning. The app
is meant to learn the actual firearm, barrel, brass, and component lots over
time, while keeping project data portable and easy to back up.

## Projects and data storage
- Each project folder contains a data folder with reloading.db.
- Export Pack bundles key data and logs into a single zip.
- Keep projects on a local drive for best performance.

## Navigation
- Workflow Hub: guided entry points for common tasks.
- Sidebar pages: Data, Analyze, Simulate, Develop, Reports, AI.
- Legacy tabs: full tool library for advanced access.

## Data import
### Chronograph
- Import chronograph files from supported devices.
- The app records source file, import time, and hash for audit trails.

### CSV
- Use CSV import when managing component data externally.
- Validate column headers and units before importing.

### GRT
- Import GRT data to populate powders and loads.
- Review validation messages for parsing errors.

## Load development workflows
- Load Development Workflow: end-to-end flow from setup to analysis.
- Seating Depth and Ladder tests are available for structured testing.
- Use notes to capture decisions and context.

## Analysis
- Historical Analysis shows sessions, comparisons, and trends.
- Compare selected sessions to spot the best SD, ES, and CI.
- Trends provide slope summaries for velocity and accuracy.

## Reports and exports
- Export selection from Historical Analysis to CSV or JSON.
- Export Pack creates a zip with data extracts, logs, and config.
- Terrain Map can export PDF summaries for coordinates.

## Settings and modes
- Beginner, Expert, and Research modes change visible features.
- Configure units and UI density in Settings.
- Use theme settings to match your preferred contrast.

## Backups and portability
- Copy the project folder for a full backup.
- Use Export Pack for portable snapshots.
- Store backups on a separate drive or cloud folder.
