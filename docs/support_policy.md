# Support Policy

Effective date: 2026-03-12

This document describes the support scope for Valkyrie Ballistics.

## 1. Support scope
We provide best-effort support for:
- Installation and first-run setup.
- Import/export workflows.
- Crash or startup failures.
- Packaging or installer issues when reproductions are provided.

We do not provide emergency support or firearms safety training.

## 2. How to request support
When reporting issues, include:
- App version and build date.
- Operating system and hardware details.
- Steps to reproduce.
- Logs from the logs folder.
- An Export Pack if the issue is data-related.

## 3. Response time
Support is best-effort. Response times are not guaranteed.

## 4. Supported versions
Support is provided for the latest released version. Older versions may
be asked to upgrade before troubleshooting continues.

## 5. Data responsibility
You control your data. Keep backups of project folders and export packs
before troubleshooting.
