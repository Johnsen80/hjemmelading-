# Onboarding Checklist

Use this checklist to complete your first setup.

- [ ] Create a new project folder.
- [ ] Set units and UI mode in Settings.
- [ ] Add rifle profiles and component data.
- [ ] Import chronograph data.
- [ ] Review sessions in Historical Analysis.
- [ ] Compare sessions and review trends.
- [ ] Export a CSV or JSON from Historical Analysis.
- [ ] Create an Export Pack for backup.
- [ ] Read safety_disclaimer.md.
