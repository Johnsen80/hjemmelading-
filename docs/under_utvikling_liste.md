# Under-utvikling-liste

Oppdatert: 2026-03-11

Denne listen samler synlige "kommer snart"-markeringer, placeholders og legacy-merking i UI og dokumentasjon. Den er ment som en praktisk oversikt over det brukeren ser som uferdig eller under utvikling.

## UI - Coming soon / placeholders
- Ingen synlige "coming soon"-markeringer i kjerneflytene.

## UI - Legacy
- `All Tools`/klassiske faner er nå merket som legacy-verktøybibliotek.
- Enkelte klassiske analyse-/testverktøy vises med `Legacy`-suffix i faner eller workflow-navn for å styre brukeren mot nyere 1.0-flyter.

## Docs - Coming soon
- Ingen Terrain Map-markering for favoritter eller PDF.

## Notater
- Listen beskriver synlige markeringer i UI. Teknisk arbeid som ikke er synlig i UI er ikke listet her.
- Tekniske forbedringer (headless smoke, packaging, logg) spores i egne notater/PR-er.
- Kostanalyse henter na data fra lager og ladeokter i stedet for demo-innhold.
